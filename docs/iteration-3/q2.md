# Q2: eval health

Status: implementation validated offline; baseline measured and gate failed.
Publication is pending review. No deployment is part of this change.

The harness supports repeated case-runs, deterministic hierarchical confidence
intervals, paired comparisons, structured error classes, machine-grouped splits
and explicit regression cohorts. CLI artifacts include transcripts, provenance
and an escaped static HTML report. Optional causal truth and report-only cohorts
support future suites; Q2 adds no cases, metrics or thresholds. The original 18
RCA cases, evaluators and agent runtime source remain unchanged.

## Retained measurement

The live baseline ran the unchanged agent and dataset from revision `fae76ff`
with the Q2 harness: 18 cases, three repeats, local target, concurrency one.
All 54 diagnoses were correct. `tool_coverage` was 0.937 (95% CI approximately
0.90–0.97), but `used_knowledge` was 0.444 (approximately 0.28–0.61), below its
unchanged 0.70 threshold. The run exited 1.

This retained failure satisfies the baseline health measurement, not green quality
acceptance. Q7 records the knowledge-citation finding. No threshold was lowered
and no rerun was used to seek a pass. No candidate improvement is claimed here.

Raw artifacts remain private and unmodified. The measured harness patch SHA256 was
`59189843c4a60c131b0eedf31e095b3dfcf6ab7b63965087650700a289f7aea1`.
It identifies the measurement patch, not the final publication diff. Provenance
records the dirty state, but HEAD alone cannot identify uncommitted harness changes.

After measurement, focused offline tests and a classification fix prevent
informational metrics, including perfect lower-is-better scores, from causing
automatic `wrong_answer` labels. Only declared minimum-score metrics participate.
Report-only selections skip regression thresholds without claiming a passing gate.
These changes do not alter the retained numerical baseline scores.

existing compatible local lock and resolving its ignored SDK pin to 1.22.0.

was not rerun: the already measured failing baseline is retained. Offline tests
establish harness behavior, not a passing model quality gate.
