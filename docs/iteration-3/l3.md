`analysis/episodes` cleans and enriches episodes and reviews, prepares
classification inputs, aggregates cached labels into ranked clusters and routes
them to a learner, knowledge proposal or backlog. Reproducing cases accompany
clusters. The answer key is accepted only by the separate benchmark command.

The default preparation command is offline and leaves candidates unlabeled.
Foundry labeling is explicit, uses structured output and a fingerprinted cache,
and requires a preflight estimate. Model traffic is not part of offline tests.
