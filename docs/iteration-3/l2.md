# L2: synthetic expert feedback

Status: implementation validated standalone and stacked on Q2; ready for review.

The deterministic generator writes separate synthetic episodes, reviews and an
answer key. It includes all five planted patterns, correct controls, reviewer
disagreement, copied reviews, a deliberately over-strict reviewer and incorrect
cause assertions. The answer key is not analysis input.

Episode records have an explicit source label. Library export/import helpers
reject wrong-source populations; synthetic bundle validation also rejects dangling
reviews and inconsistent answer-key membership. The helpers do not write to an
episode store. The full population is generated on demand, not committed.

## Standalone evidence

Validated on 2026-10-30 against base `fae76ff`, using this topic's own virtual
environment and editable workspace imports, not the integration worktree:

- `uv run ruff check`: passed.
- `uv run ruff format --check`: passed.
- `uv run pyright`: zero errors or warnings.
- `uv run pytest`: 237 passed; 24 upstream SDK deprecation warnings.
- Seed 42: 2,000 episodes and 8,300 reviews, deterministically regenerated and
  round-tripped through the three output files. Each of the five planted patterns
  has 200 failures; another 1,000 episodes are correct controls.
- The ten-episode fixture matches regeneration. Reviewer noise and source
  separation are covered by offline tests and full-population checks.

The local, ignored lock uses the existing baseline (`agent-framework-core` 1.22.0,
MCP 1.30.0). No SDK constraints or lock files are part of this change. Generated
validation artifacts remain outside tracked files. Combined integration results
are not evidence for this standalone topic.

## Cross-topic dependency

L2 includes `cs_platform.episode_io.export_episodes` and `load_episodes` for
source-separated library interchange. The local `csai diagnose` / `csai eval`
export flags are supplied by **Q2**, not by this L2 diff. The branch is stacked
on [PR #13](https://github.com/marcgs/cs-ai-platform-sample/pull/13), revision
`0450b48`. The full `csai eval rca --target local` export path therefore depends
on Q2; library export and synthetic generation do not.

## Stacked validation

After stacking, `uv sync --all-packages --offline`, Ruff, formatting and Pyright
passed. All 260 offline tests passed, including Q2's local CLI export tests for
successful and failed runs, source labels and overwrite refusal. The full gate
used this worktree's own environment with the existing compatible local lock.

No live evaluation, model calls, shared Azure changes or deployment were performed.
The live eval gate was skipped because this validation is offline; synthetic data
is not a real agent quality gate. Recovery of planted patterns belongs to L3.
